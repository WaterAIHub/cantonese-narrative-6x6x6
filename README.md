# 6³ 多元敘事包

貼一份材料，試聽三個廣東話開場，再揀一款寫成完整影片講稿。

## 開始用

一般 AI 對話用戶可以開啟 `prompt.txt`，將全文複製到新對話，填寫原始資料、目標觀眾同最想講清楚嘅問題。第一次用，打開 `docs/6³ 多元敘事包使用手冊 實作新版.docx`，跟住屋苑通告練習寫第一段口播。原有手冊收錄完整長稿同執稿例子。

Codex 用戶可以喺 GitHub 撳 Code，再揀 Download ZIP。解壓後，將 `skills/cantonese-narrative-6x6x6` 成個資料夾複製去 `~/.codex/skills/`。如果有自訂 CODEX_HOME，就放去該目錄之下嘅 skills 資料夾。開新對話後輸入：

```text
請用 $cantonese-narrative-6x6x6 幫我揀三個廣東話開場。
原始資料＝貼上已核對嘅資料同日期
講畀邊個聽＝香港一般觀眾
我最想講清楚＝寫低觀眾最想知嘅問題
```

見到三個開場後，回覆「用第二個，寫一分鐘」。想直接出稿，第一輪加「幫我揀埋」。想跟長稿格式，寫「用 Fortune Insight 模式」。只有標題時會先列出待查方向，可補貼原文或要求代查。

本 Skill 本身毋須額外 API key。搜尋同事實核對視乎使用工具同可用資料。
